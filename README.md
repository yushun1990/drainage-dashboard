# 排水管网运行智能分析平台

轻数字孪生 GIS 大屏项目，用于排水管网运行分析的投标演示。

## 技术栈

- React
- Vite
- TypeScript
- Tailwind CSS
- MapLibre GL JS
- ECharts
- 静态 Mock 数据

## 开发命令

```bash
npm run dev
npm run lint
npm run build
```

## 目录约定

- `src/components`：页面组件、面板、地图和告警展示组件
- `src/data`：静态 Mock 数据
- `src/types`：业务类型定义
- `docs`：需求、架构、任务和编码规范
